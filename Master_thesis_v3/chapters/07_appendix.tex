\section*{Appendix B: Configuration Snapshot}
\addcontentsline{toc}{chapter}{Appendix B: Configuration Snapshot}

Key configuration values for the canonical run:

\begin{itemize}
    \item Data start date: 2018-01-01; inter-request download delay: 0.3 s.
    \item Walk-forward parameters: initial train ratio 0.70, expansion step 0.05, maximum train ratio 0.95; yields 6 folds.
    \item Minimum train samples: \(400\); minimum test samples per fold: \(30\).
    \item Gate parameters: minimum predicted move $\delta = 0.004$; confidence threshold 0.58.
    \item Top-$N$ features per fold: 50. Force-include sets: global macro cues for all tickers (15 features), USD/INR and Nasdaq cues for IT sector (9 features), RBI and DXY cues for banking sector (9 features).
    \item Global cue instruments: S\&P~500, Nasdaq Composite, VIX, DXY, Brent Crude, Nikkei~225, Nifty~50, Nifty~Bank.
    \item LightGBM and XGBoost: 1000 boosted rounds, depth 5, lr 0.01, subsample 0.8, colsample 0.8, $\alpha=0.3$, $\lambda=1.5$, early stopping 50 rounds.
    \item Deep models: input sequence length 20 days, batch size 32, maximum 100 epochs, early stopping patience 8, learning rate reduction factor 0.5 with patience 8, $\ell_2 = 10^{-4}$.
    \item Random seed: 42, fixed uniformly across NumPy, scikit-learn, XGBoost, LightGBM, and TensorFlow.
\end{itemize}

\section*{Appendix F: Glossary and List of Abbreviations}
\addcontentsline{toc}{chapter}{Appendix F: Glossary and Abbreviations}

The following table expands every non-trivial abbreviation used in the body of this thesis. Stock tickers (e.g.\ SBIN, INFY, TCS) are omitted as they are reproduced in full in Appendix~A.

\subsection*{F.1 General and methodological}

\begin{description}
    \item[OOS] \textbf{Out-of-Sample} -- the held-out test slice of each walk-forward fold, i.e.\ data the model has never seen during training or validation.
    \item[IS] \textbf{In-Sample} -- the training portion of a fold.
    \item[WF / WFV] \textbf{Walk-Forward / Walk-Forward Validation} -- chronological train/validation/test splits where the train slice grows fold-by-fold; the model is retrained from scratch per fold.
    \item[CV] \textbf{Cross-Validation}.
    \item[CI] \textbf{Confidence Interval}.
    \item[NLL] \textbf{Negative Log-Likelihood} -- the loss minimised when fitting the temperature-scaling parameter $T^\star$.
    \item[DM] \textbf{Diebold--Mariano test} -- a pooled test of equal predictive accuracy between a candidate model and a benchmark, on per-period loss differences.
    \item[ES] \textbf{Early Stopping} (during gradient-boosted or neural-net training).
    \item[KPI] \textbf{Key Performance Indicator} -- the pre-registered metrics on the promotion gate that block live capital until met.
\end{description}

\subsection*{F.2 Models, learners, and architectures}

\begin{description}
    \item[ML] \textbf{Machine Learning}.
    \item[DL] \textbf{Deep Learning}.
    \item[ANN] \textbf{Artificial Neural Network}.
    \item[RNN] \textbf{Recurrent Neural Network}.
    \item[LSTM] \textbf{Long Short-Term Memory} -- a recurrent architecture with gated memory cells.
    \item[BiLSTM] \textbf{Bidirectional LSTM} -- two LSTMs reading the sequence forwards and backwards, concatenated.
    \item[GRU] \textbf{Gated Recurrent Unit} -- a lighter recurrent alternative to LSTM.
    \item[CNN] \textbf{Convolutional Neural Network}.
    \item[CNN--LSTM / CNN--GRU] Hybrid: a 1-D convolutional front-end feeding a recurrent backbone.
    \item[TCN] \textbf{Temporal Convolutional Network} -- a dilated, causal 1-D CNN designed for sequence modelling.
    \item[N-BEATS] \textbf{Neural Basis Expansion Analysis for Time Series} -- a deep stack of fully connected blocks producing backcast/forecast basis expansions.
    \item[XGBoost / XGB] \textbf{Extreme Gradient Boosting} -- regularised gradient-boosted decision trees.
    \item[LightGBM / LGBM] \textbf{Light Gradient Boosting Machine} -- histogram-based, leaf-wise gradient boosting.
    \item[RF] \textbf{Random Forest}.
    \item[SVM] \textbf{Support Vector Machine}.
    \item[NB] \textbf{Naive Bayes}.
    \item[BERT] \textbf{Bidirectional Encoder Representations from Transformers} -- a transformer-based language model (referenced in the literature survey).
    \item[RL] \textbf{Reinforcement Learning}.
    \item[GARCH] \textbf{Generalised Autoregressive Conditional Heteroskedasticity} -- a volatility model.
    \item[AR / AR(1)] \textbf{Autoregressive} model (of order one) -- a classical time-series baseline.
    \item[PCA] \textbf{Principal Component Analysis} -- linear orthogonal projection used in the XGBoost branch.
    \item[AUC] \textbf{Area Under the (ROC) Curve}.
\end{description}

\subsection*{F.3 Features, signals, and indicators}

\begin{description}
    \item[OHLC / OHLCV] \textbf{Open, High, Low, Close (Volume)} bar fields.
    \item[SMA] \textbf{Simple Moving Average}.
    \item[EMA] \textbf{Exponential Moving Average}.
    \item[MA] \textbf{Moving Average} (generic).
    \item[MACD] \textbf{Moving Average Convergence--Divergence}.
    \item[RSI] \textbf{Relative Strength Index}.
    \item[ATR] \textbf{Average True Range} -- a volatility measure used for stop sizing.
    \item[OBV] \textbf{On-Balance Volume}.
    \item[CMF] \textbf{Chaikin Money Flow}.
    \item[MFI] \textbf{Money Flow Index}.
    \item[VWAP] \textbf{Volume-Weighted Average Price}.
    \item[ADX] \textbf{Average Directional Index}.
    \item[CCI] \textbf{Commodity Channel Index}.
\end{description}

\subsection*{F.4 Risk, performance, and trading metrics}

\begin{description}
    \item[Sharpe ratio] Annualised return divided by annualised volatility, with risk-free rate set to zero.
    \item[Calmar ratio] Annualised return divided by maximum drawdown.
    \item[MaxDD / DD] \textbf{Maximum Drawdown} -- the largest peak-to-trough decline of the equity curve.
    \item[Profit factor] $\sum \text{gross wins} / |\sum \text{gross losses}|$ across closed trades.
    \item[Brier score] $\mathrm{Brier} = \frac{1}{N}\sum_i (p_i - y_i)^2$; used in the promotion-gate's $\leq 0.05$ drift threshold.
    \item[Temperature scaling] $\hat p = \sigma(\mathrm{logit}(p) / T^\star)$ with $T^\star$ fit on the validation slice by NLL minimisation. Preserves argmax, contracts/expands probabilities to match observed frequencies.
    \item[EMH] \textbf{Efficient Market Hypothesis}.
    \item[CAGR] \textbf{Compound Annual Growth Rate}.
\end{description}
